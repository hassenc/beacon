# Support

This prerelease has no production SLA. Use synthetic data until the release acceptance gates are satisfied. Public issues are for reproducible non-sensitive defects and feature requests. Private vulnerability reports must use the verified channel in SECURITY.md once publication is configured.

Deployment operators own backups, retention, access reviews, policy configuration and statutory filings. Beacon prepares records; it does not submit them to ENISA or establish legal applicability.
