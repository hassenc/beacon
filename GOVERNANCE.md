# Governance

Beacon Community is licensed under Apache-2.0. This prerelease does not promise a support SLA or represent an established community.

Maintainers review changes for scope, correctness, security and upgrade compatibility. Vulnerability response remains usable without a paid service. Commercial hosting may add operational services; it must not silently collect self-hosted case data.

Public contributions use pull requests and the repository's configured review rules. Contributors license their work under Apache-2.0 and must have the right to contribute it. No separate CLA is required. Conflicts of interest and breaking changes should be stated in the proposal.

Before a supported public release, identify maintainers, verify private security and conduct contacts, enable protected branches and security reporting, and publish a supported-version policy.
